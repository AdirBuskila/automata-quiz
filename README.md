# תרגול לאוטומטים ושפות פורמליות

מאמן מבחנים אמריקאי (עברית, RTL, מותאם לנייד) לקורס **אוטומטים ושפות פורמליות (62208)**.
תרגול חופשי עם משוב והסבר מיידי, מבחנים שלמים בזמן קצוב, סינון לפי נושא, בהיר/כהה.

- כל תשובה נלקחה מקובץ פתרון רשמי (הסימון הצהוב בפתרון) או ממבדק מודל שקיבל 100 — ללא ניחושים.
- נוסחאות מוצגות כ-MathML שנבנה מראש; התרשימים הם התמונות המקוריות מהמבחנים.
- עובד ישירות מהקובץ (`index.html`) וב-GitHub Pages, בלי שרת ובלי תלויות.

## הרצה
פתחו את `index.html` בדפדפן. קישור ישיר לתרגול נושא: `index.html?practice=nerode`.

## פיתוח
ראו `CLAUDE.md` (פקודות, זרימת נתונים, כללים) ו-`docs/build_plan.md` (תוכנית וסטטוס).
