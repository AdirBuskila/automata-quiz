## 1. ההיררכיה

$$\text{Finite}\subsetneq\text{Regular}\subsetneq\text{CFL}\subsetneq\text{All}$$

| המעבר | למה | העד |
|---|---|---|
| סופית ← רגולרית | כל שפה סופית היא רגולרית (ביטוי רגולרי: איחוד של מילים) | — |
| רגולרית ← ח״ה | אס״ד הוא אוטומ״ח שלא נוגע במחסנית; יש דקדוק ליניארי ימני | — |
| רגולרית, לא סופית | | $a^*$ |
| ח״ה, לא רגולרית | | $\{a^nb^n\}$ |
| לא ח״ה | | $\{a^nb^nc^n\}$ |

> 🔑 **ההכלות גורמות לאופציות להיות מוציאות זו את זו:** אם השפה רגולרית ואינסופית, אז ג׳ ("לא-רגולרית") ו-ד׳ ("לא-ח״ה") **שגויות אוטומטית**. לכן **תמיד שואלים מלמטה למעלה:** סופית? רגולרית? ח״ה?

## 2. אלגוריתם הסיווג

1. **פשט את השפה לפני הכול.** מחצית מהמלכודות נפתרות כאן:
   - $i\le k\le m\le i$ ← $i=k=m$ (`23A-B-Q8`).
   - $ab^nb^na$ ← $a(bb)^+a$ (`21S-A-Q8`).
   - $\{xyz\mid |x|\le|y|\le|z|\}$ ← $\Sigma^*$ (קח $x=y=\varepsilon$; `23A-A-Q8`).
   - $\{uv\mid |u|=|v|\}$ ← $(\Sigma\Sigma)^*$ (`21S-B-Q20`).
   - שפה בתוך כוכבית שמכילה את $a$ ← $a^*$ (`25A-C-Q2`).
   - איחוד שבו אחד החלקים **מוכל** בשני ← החלק הגדול (`21S-A-Q19`).
2. **האם היא סופית?** אורכים חסומים ← סופית ← רגולרית.
3. **האם היא רגולרית?** חפש ביטוי רגולרי או אס״ד. סימנים: תבנית קבועה, ספירה **מודולו**, ספירה **עד קבוע**, "או $i>50$" שבולע את הכול.
4. **אם לא נמצא, הוכח לא-רגולריות:**
   - **קבוצה מפרידה אינסופית**, בדרך כלל $\{a^i\}$ או $\{a^ib^i\}$ ([[07 - משפט נרוד ומינימיזציה]]);
   - או חיתוך עם רגולרית שנותן שפה לא-רגולרית ידועה (`24A-B-Q13`, `24X-C-Q11`).
5. **האם היא ח״ה?** חפש דקדוק או אוטומ״ח. או **הרכב** מח״ה ידועות: איחוד, שרשור, חיתוך עם רגולרית.
6. **אם לא, הוכח לא-ח״ה:**
   - חיתוך עם רגולרית שנותן לא-ח״ה ידועה (`25A-B-Q17`, `25A-C-Q6`);
   - או למת הניפוח ([[10 - תכונות שפות חסרות הקשר]]).

### הכלל האינטואיטיבי: כמה "זיכרון" צריך?

| צריך לזכור | המחלקה |
|---|---|
| כמות **חסומה** (עד קבוע, מודולו, תבנית) | **רגולרית** |
| **מונה אחד** שעולה ואז יורד, בסדר **מקונן** | **ח״ה** |
| **שתי השוואות בבת אחת**, או השוואות **חוצות** | **לא ח״ה** |

> 🔑 **מקונן מול חוצה — ישר מדף הנוסחאות:**
> $a^nb^mc^md^n$: המונים **מקוננים** (כמו סוגריים) ← **ח״ה**.
> $a^nb^mc^nd^m$: המונים **חוצים** ← **לא-ח״ה**.
> המחסנית היא LIFO: מה שנדחף אחרון נשלף ראשון. היא יכולה לבדוק זוגות שנסגרים בסדר הפוך לפתיחה, ולא זוגות שנסגרים באותו סדר.

## 4. שפות מעל אות אחת ($\Sigma=\{a\}$)

- **לא כל שפה אונרית רגולרית:** ✅ ב-`21S-A-Q10`, הדוגמה היא $\{a^p\mid p\text{ prime}\}$.
- **בדף הנוסחאות:** $a^{n^2}$, $a^{n!}$ ומשלימותיהן **לא ח״ה**.
- **ראשוניים:** המקורות רק אומרים "לא-רגולרית". אם צריך לא-ח״ה, זו הוכחה בלמת הניפוח: $w=a^p$ עם $p\ge\ell$ ראשוני, $d=|yu|\ge1$, ובחירה $n=p+1$ נותנת אורך $p+pd=p(1+d)$, שאינו ראשוני.

> ⚠️ **"כל שפה ח״ה מעל אות אחת היא רגולרית"**: המשפט הזה (נכון, תוצאה כללית) **לא מופיע בדף הנוסחאות ולא בסיכומים שבדקתי**. הפתרון הרשמי של `26A-A-Q17` לא משתמש בו; הוא משרשר את $L$ עם $\{a^{2025}\}$, מקבל את הריבועים $\{a^{k^2}\}$ מדף הנוסחאות, ומגיע לסתירה. **במבחן השתמש ברשימה של דף הנוסחאות.**

### ⭐ `26A-A-Q17` — $\{a^{k^2-2025}\mid k\ge2026\}$

1. השפה אינסופית ← א׳ נפסלת.
2. נניח שהיא ח״ה. שרשור עם הסופית $\{a^{2025}\}$ שומר על ח״ה, ומתקבל $\{a^{k^2}\mid k\ge2026\}$.
3. היא שונה מ-$a^{n^2}$ (מדף הנוסחאות) רק במספר סופי של מילים. אילו הייתה ח״ה, איחוד עם המילים החסרות (שפה סופית) היה נותן ש-$a^{n^2}$ ח״ה ← סתירה.

✅ **לא-ח״ה.** (שים לב שהפתרון הרשמי כותב $k\ge1$ במקום $k\ge2026$; זה לא משנה את התשובה.)

### ⭐ `25A-C-Q2` — המלכודת הכי אלגנטית

$$L=\left(\{a^{n^2}\mid n\ge1\}\cup\{aa\}\right)^*$$

"ריבועים" ← הרפלקס אומר לא-ח״ה. **אבל** עבור $n=1$, $a^{1}=a$ נמצאת בתוך הכוכבית ← $L=a^*$.
✅ **רגולרית ואינסופית.**

> 🪤 **כוכבית של שפה שמכילה אות בודדת $a$ (מעל $\{a\}$) היא תמיד $a^*$.** בדוק תמיד את המקרה $n=1$ ואת $n=0$.

## 5. ⭐ שאלות-מפתח לפי סוג

### ⭐ `24A-A-Q2` — שני תנאים דומים, תשובות הפוכות

$$L_1=\{a^nb^m\mid n+3m\le2024\}$$
$$L_2=\{a^nb^m\mid n-3m\le2024\}$$

- $L_1$: **סכום** חסום ← גם $n$ וגם $m$ חסומים ← **סופית** ← רגולרית.
- $L_2$: **הפרש** חסום ← $n$ יכול לגדול כל עוד $m$ גדל איתו ← צריך "לזכור" את $n$ ← **לא-רגולרית**.

✅ **$L_1$ רגולרית, $L_2$ לא.** ב-`24X-A-Q2`, גם $L_1$ ($n\le100\le k$) וגם $L_2$ ($n+k\le100$) ✅ רגולריות.

> 💡 **סכום חסום של מונים אי-שליליים ← סופי. הפרש חסום ← בדרך כלל אינסופי ולא-רגולרי.**

### ⭐ `25A-B-Q17` — חיתוך עם רגולרית חושף מבנה חוצה

$L=\{w\mid\#_a=\#_c\wedge\#_b=\#_d\}$. האותיות מעורבבות, ולכן קשה לנפח ישירות.

$$L\cap a^*b^*c^*d^*=\{a^nb^mc^nd^m\}$$

זו שפה **חוצה** מדף הנוסחאות ← לא-ח״ה ← גם $L$ לא-ח״ה. ✅

> 🔑 **"$L$ ח״ה ← $L\cap R$ ח״ה".** לכן אם $L\cap R$ **לא** ח״ה, גם $L$ לא. **בחר $R$ שמסדר את האותיות בגושים.**

### ⭐ `19B-B-Q18` — "או" שבולע

$\{a^ib^jc^k\mid i=j=k\ \lor\ i>50\}$. החלק $i=j=k$ עם $i\le50$ הוא **סופי**; השאר הוא $a^{51}a^*b^*c^*$.
✅ **רגולרית ואינסופית**, למרות ש-$a^nb^nc^n$ מופיעה בהגדרה.

| `25A-B-Q15` | $(111)^*(000)^*+(01)^*(10)^*$ | רגולרית ואינסופית |

## 7. טענות כלליות — 7 שאלות

| שאלה | ✅ | הרעיון |
|---|---|---|
| `24A-B-Q3` | תנאי **הכרחי** ללא-רגולריות: **$L$ וגם $\overline L$ אינסופיות** | אם אחת סופית ← שתיהן רגולריות |
| `23A-A-Q3` | תנאי הכרחי **ומספיק** לרגולריות: **אף אחד** | פלינדרומים ומשלימתם אינסופיות; $(\Sigma\Sigma)^*$ ומשלימתה אינסופיות |
| `26A-A-Q6` | $L\subseteq L'$, שתיהן אינסופיות: **ייתכן** $L$ רגולרית ו-$L'$ לא | $a^*\subseteq\{\#_a\ge\#_b\}$ |
| `26A-A-Q15` | $L$ סופית ← **יש אוטומ״ח** ל-$\overline L$ | סופית ← רגולרית ← המשלים רגולרי ← ח״ה |
| `21S-A-Q13` | $L$ רגולרית, $L'=L\cap\{\#_a=\#_b\}$ ← **ח״ה, וייתכן שרגולרית** | $L=a^*$ ← $\{\varepsilon\}$; $L=a^*b^*$ ← $a^nb^n$ |
| `SAMP-19-Q19` | $L'\subseteq L$, $L$ ח״ה לא-רגולרית ← **ייתכן** $L'$ רגולרית | $\{\varepsilon\}\subseteq\{a^nb^n\}$ |
| `21S-A-Q19` | $L_2\subseteq L_1$ ← $L=L_1$ **רגולרית** | $1^{2n}0^k1^k$ מתאים לתבנית $(11)^*0^*1^*$ |

> 🔑 **הכלה לא אומרת כלום על מחלקה.** $\{ab,a^2b^2\}\subseteq\{a^nb^n\}$ היא סופית (`26A-A-Q6`). $\{a^nb^n\}\subseteq\Sigma^*$ לא-רגולרית בתוך רגולרית.

> 🪤 **`26A-A-Q15` + CNF:** המחוון קובע שיש ל-$\overline L$ דקדוק ב-**CNF**, גם כש-$\varepsilon\in\overline L$. זה עקבי עם $S\to\varepsilon$ מותר (ראה [[08 - דקדוקים חסרי הקשר]]).

## 11. צ׳קליסט לפני המבחן

- [ ] **פשט קודם:** $i\le k\le m\le i$ · $ab^nb^na$ · $|x|\le|y|\le|z|$ · כוכבית שמכילה $a$
- [ ] שאל מלמטה למעלה: סופית? רגולרית? ח״ה?
- [ ] "סופית" לא הייתה אף פעם התשובה, אבל היא שלב ביניים נהדר
- [ ] מודולו / "לפחות $k$" / תבנית ← **רגולרית**
- [ ] מונה אחד מקונן ← **ח״ה**. שני מונים חוצים או שוויון משולש ← **לא ח״ה**
- [ ] דף הנוסחאות: $a^nb^n$, $a^nb^mc^md^n$, $uu^R$, $\overline{uu}$ ← ח״ה לא-רגולריות
- [ ] דף הנוסחאות: $a^nb^nc^n$, $a^nb^mc^nd^m$, $uu$, $a^{n^2}$, $a^{n!}$ ומשלימותיהן ← לא ח״ה
- [ ] יש דקדוק / אוטומ״ח ← ח״ה, **אבל פענח** לפני שאתה בוחר "לא-רגולרית"
- [ ] לא-רגולרית: קבוצה מפרידה $\{a^i\}$ או חיתוך עם רגולרית
- [ ] לא-ח״ה: חיתוך עם $a^*b^*c^*\cdots$ שמחזיר שפה מהדף, או למת הניפוח
- [ ] סכום חסום ← סופית. הפרש חסום ← לא-רגולרית (`24A-A-Q2`)
- [ ] "או" עם תנאי רחב ($i>50$) יכול לבלוע את החלק הקשה (`19B-B-Q18`)
- [ ] וריאציית פלינדרום ← ח״ה ולא-רגולרית
- [ ] אות אחת: $a^{n^2}$ לא ח״ה (מהדף); ובדוק את $n=1$ בתוך כוכבית (`25A-C-Q2`)
